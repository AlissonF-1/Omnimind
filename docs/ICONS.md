# Ícones do OmniMind

Importe os ícones de `@/components/icons`. Use os componentes do kit OmniMind para representar áreas e conceitos do produto, como `AcademyIcon`, `TutorIcon`, `LearningPathIcon`, `QuestionsIcon` e `ReviewsIcon`. Use os controles Solar Bold Duotone para operações como voltar, fechar, copiar, salvar e pesquisar.

O kit original tem 30 desenhos. Os ícones do produto usam duotone por padrão e aceitam `mode="mono"` e `mode="color"`. Reserve a versão colorida para destaques com mais espaço. O tamanho segue o atributo `size`, em pixels quando numérico.

Ícones ao lado de texto são decorativos por padrão. Em um botão que só tem ícone, mantenha o nome acessível no botão com `aria-label`. Para um ícone informativo isolado, use a propriedade `label`.

Os desenhos são componentes SVG locais. A seção de configurações também exibe o crédito dos controles Solar.
